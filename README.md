# Sandbox.io - Agri-Fintech & Rural Investment Platform

Official web presence and investment portal for **Sandbox.io (Sandbox Technology Limited)**, bridging global and local investors with verified, asset-backed, Shariah-compliant rural opportunities .

## 🚀 Features
- **Active Investment Campaigns:** Filterable marketplace for agriculture, fisheries, livestock, and SME trading projects.
- **Shariah-Compliant Framework:** Transparent, asset-backed Murabaha financing structures.
- **Fully Responsive Design:** Optimized layouts for both desktop and mobile devices.

## 🛠️ Tech Stack
- **HTML5 & CSS3** (Vanilla, modern CSS variables, clean layout grid)
- **JavaScript** (Dynamic filtering and UI interactivity)

## 📂 Project Structure
- `index.html` - Homepage with macro stats and featured campaigns.
- `projects.html` - Filterable active campaigns and project catalog.
